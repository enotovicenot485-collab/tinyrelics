# Tiny Relics

Небольшой мод для Minecraft с двумя предметами.

| Папка | Версия игры | Загрузчик | Java |
|---|---|---|---|
| `forge-1.20.1` | 1.20.1 | Forge 47.x | 17 |
| `neoforge-1.21.1` | 1.21.1 | NeoForge 21.1.x | 21 |

## Предметы

**Амулет сохранения** (`tinyrelics:keeping_charm`)

- Если в инвентаре есть амулет, после смерти все вещи остаются у игрока.
- На каждую смерть тратится один амулет. После возрождения он всплывает перед экраном и разламывается.
- Складывается до 16 штук. Опыт не сохраняет.
- Крафт: слева и справа по три золотых слитка, в среднем столбце сверху вниз алмаз, сундук, жемчуг Края.

**Молот Тора** (`tinyrelics:thor_hammer`)

- Правая кнопка мыши: молнии бьют по всем существам в квадрате 35×35 блоков вокруг игрока (по высоте ±12 блоков). Перезарядки нет.
- Каждая молния наносит 20 урона (10 сердец) и поджигает цель. Самого владельца, его приручённых питомцев и стойки для брони молот не трогает. Молнии не поджигают землю.
- В руке искрит. Обычный удар: 14 урона.
- Рецепта нет, берётся только в творческом режиме (вкладка «Оружие») или командой `/give`.

## Как получить .jar

После каждого изменения в ветке `main` GitHub сам собирает мод. Готовые файлы лежат в разделе **Releases** репозитория. Если сборка не прошла, причина видна на вкладке **Actions**.

## Сборка на своём компьютере

Нужен JDK 21 (для Forge 1.20.1 ещё и JDK 17, Gradle скачает его сам).

```
cd forge-1.20.1
./gradlew build renameJar

cd neoforge-1.21.1
./gradlew build
```

Готовый файл появится в `build/libs`. Для Forge нужен файл без слова `unobfuscated` в названии.
